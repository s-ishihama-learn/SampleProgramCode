| ファイル名 | リポジトリ上の形式 | 概要 |
| :--- | :--- | :--- |
| **`python.md`** | マークダウン / スニペット | Pythonの標準ライブラリ（日付操作、文字列処理、標準出力）や基本データ構造の便利テクニック集 |

## 🛠 各ドキュメントの詳細内容

### 1. `python.md` (Pythonコードスニペット集)
Pythonを使った開発で頻繁に利用する汎用的な処理をまとめています。
* **出力・ファイル操作**: `print` 改行抑制、`tempfile` を用いた一時ファイル処理、NumPyからのCSV出力
* **データ構造・文字列**: 2つのリストからの辞書生成、SQL検索用の文字列結合、ゼロ埋めフォーマット、`NaN` 除外
* **日付・時間操作 (`datetime`)**:
  * 日付文字列と `datetime` オブジェクトの相互変換
  * `timedelta` による日時の加算・減算
  * 指定期間（開始日〜終了日）の日付リスト生成
  * 深夜時間帯（0〜4時）を前日24〜28時として扱う **29時間制変換ロジック**

### 2. `pandas.md` (pandas 処理パターン・スニペット集)
データ分析やETL処理で役立つ `pandas` の具体的な書き方を網羅しています。
* **データ入出力・抽出**: CSV読み込み、特定の行列変更、条件指定フィルタリング、辞書/リスト変換
* **データ整形・加工**:
  * 列の削除・順序変更・名前変更
  * ソート、重複行の削除および抽出
  * `fillna` を用いた欠損値の穴埋め・列間での補完
* **高度な処理・応用**:
  * `apply` / `lambda` による複数引数・複数戻り値関数の適用
  * 縦横変換（ピボット操作）および `groupby`（累積カウント、前値補完）
  * DBからのデータ取得と JSON への出力
  * `swifter` による `apply` 処理の高速化・並列化

### 3. `comprehension.md` (Python リスト操作・内包表記サンプル集)
コードの可読性や記述効率を高めるリスト操作と内包表記のパターン集です。
* **二次元リストの一次元化 (Flatting)**: 多重ループを内包表記で記述する手法
* **時間数値の変換**: 数値リスト（例: `515`）から `datetime.time(5, 15)` への一括変換
* **内包表記の応用**: SQL文字列の動的生成、三項演算子を使ったネスト置換、`zip()` を組み合わせた辞書作成
* **コードの簡略化 (リファクタリング)**:
  * `for` ループ判定処理から `all()` + ジェネレータ式への書き換え
  * インデックス指定での配列加算から `zip()` + リスト内包表記への書き換え

### 4. `linux_shell.md` (Bash シェルスクリプト・コマンドパターン集)
Linux環境でのバッチ処理や運用タスクに役立つシェルスクリプト集です。
* **日付ループ処理**: `date` コマンドを利用した YYYYMMDD や YYYY-MM-DD 形式の日次ループ
* **ログ・ファイル出力**: 年月 (`YYYYMM`) を付与したログファイル出力、本日日付の書き出し
* **定期的実行**: `watch` コマンドを使ったプロセス監視やファイル更新のモニタリング
* **ファイル・テキスト処理**:
  * ディレクトリ内の特定拡張子 (`.tar`) の一括解凍ループ
  * リストファイルを1行ずつ読み込んで実行する `while read` 処理
  * 再帰的なディレクトリ構造からのファイル数カウント
